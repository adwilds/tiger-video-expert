# 老虎AI全链路内容操盘手 · tiger-video-expert

全链路内容操盘手。不是"帮我想个选题"的助手，只负责两件事：
**判断这个内容值不值得做**，以及**把它拆成能今天开工的工序**。

## 它解决什么问题

短视频的失败大多不发生在剪辑台上，发生在开工之前——选题说不清给谁看，
或者脚本没有悬念，或者录完了才发现素材不够。这个专家把这些判断放在最前面，
并且敢否掉选题。

## 完整链路

```
身份 → 情报 → 选题 → 脚本 → 素材 → 粗剪 → 草稿 → 分发 → 复盘
 人     脚本   人判断    人     人     脚本    脚本    脚本   人决策
```

上游两段是输入，选题是判断，后面才是执行。

## 交付物

- **身份卡**：账号名、赛道关键词、目标观众（职业 + 处境 + 在愁什么）、内容目标；观众写"年轻人"会被拦下
- **选题候选**：按赛道匹配、热度、时效、可验证、可拍五项客观特征排序，多源共报会合并成一条
- **选题判断**：四关（具体性 / 可验证 / 反常识 / 拍摄可行性），过不了三关就否掉，并给替代角度
- **脚本**：按"抛出问题 → 推进 → 兑现或反转"三段结构写，数字必须带来源
- **粗剪草稿**：算出该保留哪些句子、跳点用哪个机位盖住，产出能直接导入剪映继续精修的草稿
- **结构体检**：钩子 / 结构 / 信息密度 / 平台适配四项打分，指出拖后腿的地方和改法；有 3 条以上历史数据时才附量级区间
- **发布稿**：抖音 / 小红书 / 视频号 / X 四个平台各一版，带发布前检查表

## 它不做什么

- 不保证播放量、完播率、涨粉。只保证结构成立、事实站得住、工序能跑
- **不预测播放量、点赞、评论的具体数字。** 平台推荐不可观测，给了也是编的
- 不替你填选题卡的四栏，也不替你下"做 / 不做"的结论——它没有你的素材和处境
- 不编情报。情报只来自你给的源，或对话里真实检索到的结果
- 不自动点"发布"。最后一下留给人——平台端自动发布的失效方式是静默的
- 不逆向剪映的加密格式
