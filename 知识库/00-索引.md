# 内容知识库 · 索引

这里是**判断的依据**，不是产物的仓库。成片在剪映，草稿和发布稿在项目目录里，这里只沉淀「下次还能用」的东西。

## 怎么长

一次循环写三篇，不要多写：

1. **选题卡**（模板：`99-模板/选题卡.md`）——结论是「做 / 不做 / 换角度」，不做的也要留，否则下周会重新想一遍同样的题。
2. **复盘**（模板：`99-模板/复盘.md`）——写结论，不抄后台数字。数字在 `07-metrics/metrics.csv` 里。
3. **技巧**（改现有笔记，不新建）——同一个坑踩第二次，就把它补进 [[切点规则]] 或 [[精剪SOP]]。

## 两条硬规矩

- **选题类型只用四种**：`反常识` `拆解` `复盘` `热点`。`metrics log --topic-type` 必须用这四个词之一，写别的词，数据就聚不起来。
- **模板里的字段不要删**。删了以后翻旧笔记会发现一半有、一半没有，等于没有。

## 和流水线的关系

```
对话：判断（选题/脚本/复核/解读）
工作台：看状态（.\run.cmd board）
知识库：留依据（本库）
项目目录：留产物（剪映草稿、四平台稿、metrics.csv）
```

四者不重复。判断写在这里，产物留在项目里。
