# 切点规则

切点算的是「**保留什么**」，不是「删什么」。

两种错误的代价不对称：漏删一句废话 = 啰嗦两秒；误删一个「但是」= 因果断裂，而且成片里听不出来。所以默认保留，只有明确命中删除规则才切。

## 永不删：保护词

命中任一即强制保留，即使它看起来像废话：

```
但是 但 可是 然而 不过 其实 所以 因为 因此 于是
换句话说 也就是说 问题是 关键是 重点是 核心是 本质是
不是 并不 没有 反而 恰恰
```

这张表是 `cutlist.py` 里的 `PROTECTED`，改表就改行为，不用改算法。

## 才删：三类明确废话

| 类别 | 内容 | 条件 |
|---|---|---|
| 语气词 | 嗯 啊 呃 那个 就是说 然后呢 对对对 对的对的 | **整句除语气词和标点外没有实质内容**才删 |
| 拍摄指令 | 等一下 重来 卡了 停一下 再来一遍 不好意思 重新说 | 命中即删 |
| 自我纠正 | 不对 说错了 不是这样 | 命中即删 |

语气词是「独立出现才删」。句子里带着「那个方案」不删——删了句子就断了。

## 停顿：压缩，不是丢掉

机械删静默会让人听着喘不上气。默认值：

| 参数 | 默认 | 含义 |
|---|---|---|
| `silence_target` | 0.35s | 普通停顿压到多长 |
| `breath_pause` | 0.80s | 思考性停顿保留多长 |
| `think_pause` | 2.5s | 超过这个长度算真静默，不算思考 |
| `min_keep_gap` | 1.0s | 间隙小于此值不切开，防碎剪 |
| `padding` | 0.15s | 保留区间两端外扩，避免咬字 |
| `similar` | 0.92 | 相邻句相似度阈值，判重录用 |
| `max_shrink` | 0.35 | 总时长缩短上限，超了告警 |

调法：切太狠 → 调大 `silence_target`；切太碎 → 调大 `min_keep_gap`。

## 人工复核是流程的一部分

`cut` 之后必须看 `04-cut/切点对照表.md`。算法不懂语境，看到删错的把那句标成：

```json
{ "text": "这句不能删", "keep": true, "manual": true }
```

重跑 `cut`，算法不再动它。**这一步跳过，就是拿成片赌。**

## 判据写在表里

每条切点都带「依据」：首句强制保留 / 末句强制保留 / 保护词「但是」/ 独立语气词 / 人工指定。看不懂为什么切，就是表没写清，不是算法有问题。
