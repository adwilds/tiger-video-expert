## 一、上架前必须先定的两件事

**1. 付费模式（发布后不可修改）**

平台规则：一次性买断 / 按月订阅，**上架发布后后期不能改**。所以这一项要在点提交之前想清楚。

- 一次性买断：适合更新频率低、功能固定的内容
- 按月订阅：适合会持续迭代的

如果你还没想好，就**先免费上架**。免费不涉及付费模式，先把使用量和评价跑出来，
等确认有人真的在用、并且愿意付钱，再谈收费。反过来（先收费后改免费）体验更差。

### 一句话介绍

```
先定清楚账号身份和说给谁听，按赛道自动采情报、排选题候选，再按钩子写脚本，交付能继续精修的剪映草稿。
```

### 详细介绍

```
短视频的失败大多不发生在剪辑台上，发生在开工之前——说不清账号到底做给谁看，选题靠刷到的感觉，
录完了才发现素材不够。这个专家把判断放在最前面，并且敢否掉选题。

【完整链路】
身份 → 情报 → 选题 → 脚本 → 素材 → 粗剪 → 草稿 → 分发 → 复盘。
上游两段是输入，选题是判断，后面才是执行。

【它做什么】
· 定身份：账号名、赛道关键词、目标观众（职业 + 处境 + 正在为什么发愁）、内容目标四选一。
  观众写成「年轻人」「上班族」会被直接拦下——这不是挑刺，观众说不清，后面每一关都没有靶心。
· 采情报：按你配的源抓 RSS/Atom，跨期累积；抓到的东西自动去重，同一条被多家报道会合并成一条，
  标出「N 个源在说同一件事」。你在别处看到的好东西也能结构化喂进去。
· 排选题：按赛道匹配 35%、热度 25%、时效 20%、可验证 10%、可拍 10% 五项客观特征打分排序，
  每条给出「为什么排在这」。分数高只说明值得看一眼，不说明值得做。
· 落选题卡：把选中的候选变成一张带情报依据的卡（标题、来源、日期、链接、打分），
  **四栏故意留空**——一句话选题、目标观众、反常识点、素材清单，你来填。
· 写脚本：按「抛出一个必须被回答的问题 → 给出推进它的具体信息 → 兑现或反转」三段结构写，
  里面的数字必须能追溯到来源，找不到就降级成「假设」并在脚本里明说，不许编。
· 出粗剪草稿：算出该保留哪些句子、哪几处跳点用第二个机位盖住，产出能直接导入剪映继续精修的草稿。
· 多平台成稿：抖音、小红书、视频号、X 各一版，附发布前检查表（硬性约束、吃亏点、人工确认项）。

【它不做什么】
· 不保证播放量、完播率、涨粉。只保证结构成立、事实站得住、工序能跑。
· 不替你填选题卡的四栏，也不替你下「做 / 不做」的结论。它没有你的素材、处境和表达习惯。
· 不编情报。情报只来自你给的源，或对话里真实检索到的结果。
· 不自动点「发布」。平台端自动发布的失效方式是静默的——账号被限流你不一定知道。
· 不逆向剪映的加密格式。
```

### 使用说明

```
四种典型用法，从最上游开始：

0）不知道下一条做什么
   说「帮我看看最近有什么值得做的」。它会先问你的账号定位和目标观众——这一步跑不掉，
   因为后面所有判断都靠它。定完身份，它按你的赛道抓情报、排出候选表，并标出哪些是多源共报。
   你挑一条，它落成选题卡；四栏还得你填，填不满就写「不做」。

1）只有选题想法
   直接说「我手上有一个选题，帮我判断值不值得做」。它会先问清楚这条给谁看、
   有没有素材、能不能找到数据来源，再给结论。被否掉是正常结果，它会同时给替代角度。

2）已经录完了
   说「片子录完了，帮我找该删的地方」。把转写文本或录音给它，它会算出保留清单、
   跳点位置和字幕切分，产出粗剪草稿。

3）要做分发
   说「写四个平台的发布稿」。它会按各平台的字数、话题、时长甜点区间分别出稿，
   并标出哪几处会吃亏。

需要自备：素材（实拍或录音）、能描述清楚的选题背景、一份你会长期跟的情报源清单。
```

### 风险提示 / 使用限制

```
· 内容中的数字、引用需要你自己复核。它会标出来源，但不替你担保第三方数据的准确性。
· 不承诺任何流量结果。选题判断是提高命中率的工具，不是保证。
· 涉及肖像、音乐版权、平台规则的部分，需要你自行确认授权。
· 草稿交付的是「可继续精修的版本」，剪映里的精剪和导出仍需人工完成。
```

## 三、上传步骤

1. 打开 <https://open.workbuddy.cn/dashboard>，完成开发者入驻 / 认证（你已登录，确认认证状态即可）
2. 左侧进入「发布管理」→ 专家发布，上传 `dist/tiger-video-expert.zip`
3. 按上面第二节填字段，设置封面和标签
4. 选择付费模式（见第一节的建议）
5. 提交审核
6. **审核通过与正式发布是两个不同状态**，两边都要确认一次，别停在「审核通过」就以为上架了

平台解析失败时，错误会指向 `.codebuddy-plugin/plugin.json` 或目录结构；
定位不了可发邮件到 openworkbuddy@tencent.com。
